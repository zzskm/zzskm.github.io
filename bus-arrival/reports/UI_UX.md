# 출발 판단 중심 UI와 운행 타임라인

화면은 출발 권장까지 남은 시간, 도착 예상, 조기 도착 대비 기준을 구분한다. `alarm.js`의 최신성·보정 판단과 실제 예약 결과를 `dashboard.js`의 순수 표시 함수에 전달한다. 알림 엔진과 보정 모델은 변경하지 않는다. 날짜와 시각은 한국 시각이다.

## 화면과 상태

- 출발 판단 → 이번 버스 타임라인 → 현재/다음 차량 → 알림 요약 → 예측 변화 → 최근 운행 → 같은 요일 비교 → 알람·타이머 순서다.
- 도보·추가 여유·N분·시간대는 접이식 설정이며 변경 즉시 실제 엔진으로 다음 알림을 다시 계산한다. 기존 localStorage 키를 유지한다. 시각 알람·타이머 입력은 접고 활성 목록은 노출한다.
- 화면·탭 제목·파비콘은 출발 권장 기준을 공유한다. 후속 차량이 알림 대상이면 그 차량의 알림이라고 명시한다.
- 최신 자료가 없는 첫 접속에서는 출발 예정을 만들지 않는다. 이미 검증된 예약만 살아 있는 경우 '이전 정보 기준 예약 경고'로 구분하며 최신 도착 예상처럼 카운트다운하지 않는다.
- API 예상 시각이 지나도 실제 통과로 확정하지 않는다. `no_bus`도 실제 운행 없음으로 단정하지 않는다. 기존의 검증되지 않은 '오차 ±3분' 문구를 제거한다.
- 모델 근거를 과거 운행 분위수·고정 11분·오래된 모델 여유 유지로 구분한다. 이 표시는 실제 도착 또는 안전 보장을 뜻하지 않는다.

## 타임라인의 출처

채운 점은 최초/최근 차량 관측과 이 브라우저가 실행한 알림, 빈 기호는 다음 알림·출발 권장·조기 대비 기준·보정 예상이다. 예정 시각이 지나도 실제 출발/도착 완료로 바꾸지 않는다. 알림 실행은 OS 알림 전달이나 사용자의 수신 확인이 아니다.

`first_seen_ts`가 있으면 수집기의 최초 관측을 사용한다. 없으면 '표시 가능한 기록 시작'으로 표현한다. 최근 요약 30건을 전체 운행 이력으로 부르지 않는다. 차량 ID가 재사용되어도 다른 차량/버스 없음 행과 최초 관측 경계를 넘어 이력을 연결하지 않는다. 원시 로그나 공개 스키마를 수정하지 않는다.

알림 실행 기록은 별도 `busDashboard.v1.events`에 최근 40개만 저장한다. 다른 브라우저와 동기화되지 않으며 저장소가 차단되면 기록이 유지되지 않을 수 있다. 기존 발화 원장은 변경하지 않는다. 차량 건너뛰기는 30초간 되돌릴 수 있고 Web Locks를 사용해 해당 건너뛰기 항목만 지운다. 이미 실행한 알림 기록을 초기화하지 않는다.

## 그래프

기본 그래프는 조회 시각에 따른 API 도착 예정 시각 변화다. '남은 시간' 보기로 전환할 수 있다. 조회 간격의 2.5배(최소 3분)를 넘는 공백은 연결하지 않는다. 이는 선을 끊는 표시 기준이며 도착 판단/알림 임계값은 아니다.

현재 보정 예상과 조기 대비 기준은 마지막 조회 위치의 기호로만 표시한다. 당시 보정 이력이 없으므로 현재 모델을 과거 시점에 소급해 선으로 그리지 않는다. 두 값 사이를 95% 도착 구간으로 표시하지 않는다. 수집 시간 외·최신 판단 불가 때는 현재 보정 기호를 숨긴다. API 기록 표와 설명을 함께 제공한다.

같은 요일 비교는 지난 28일 중 오늘 이전의 `observed_arrival`/`estimated_arrival` 운행을 점 하나로 표시한다. 중복 차량/운행 시작은 제거하고 공백/추적 중단 유형은 제외한다. 'observed_arrival'도 추정 도착일 수 있으므로 전체 그래프를 추정 기록으로 명시한다. 비교는 전체 시간대이고, 기존 알림 시간대별 요약과 구분한다. 다음 배차 예측이나 사전 알림의 학습 근거를 추가 생성하는 기능이 아니다.

## 검증

- 순수 표시 함수: 출발 계산·엔진 예약 일치, 후속 차량 분리, 오래된 최초 접속, 예약 유지, 시간 외/휴일, 시계 오류, 예정/관측 구분, 차량 ID 재사용, 공백, 운행 표본 중복 제거를 Node로 검증한다.
- 기존 Python 수집/통계·안전 모델·엔진 재생과 알림/시각 알람/타이머의 Node 회귀 검사를 유지한다.
- Chromium: 설정 저장/재로드, 실제 다음 알림 미리보기, 189초 예약 경고, 건너뛰기 되돌리기, 그래프 전환/만료, 360·390·1280px/다크/감소 동작, 운행 비교, 접힌 입력 폼에서 알람·타이머 동작을 확인한다. CI에서 브라우저 검사를 필수로 수행하고 스크린샷을 artifact로 보관한다.

외부 API 호출·비밀키·로그 재생성은 필요 없다. 로컬 샌드박스는 소켓/Chromium 실행을 제한하므로 브라우저 결과는 PR CI로 확인한다. 실제 버스 도착, OS 알림 전달, Pages 배포 지연을 새로 측정한 변경은 아니다.
